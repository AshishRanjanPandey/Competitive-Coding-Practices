# ⚡ Codeforces 1742A — Sum

### 📝 Problem Description
You are given three integers $a$, $b$, and $c$. Determine if one of them is the sum of the other two.

**Input:**
- The first line contains a single integer $t$ ($1 \le t \le 9261$) — the number of test cases.
- Each of the following $t$ lines contains three integers $a$, $b$, and $c$ ($0 \le a, b, c \le 20$).

**Output:**
- For each test case, output `"YES"` if one of the numbers is the sum of the other two, and `"NO"` otherwise.
- The output is case-insensitive (e.g., `"YES"`, `"yes"`, and `"Yes"` are all accepted).

---

### 💡 Key Insights
1. **Direct Condition Check:**
   - Any of the three variables can potentially be the target sum:
     - $a + b = c$
     - $a + c = b$
     - $b + c = a$
   - Testing these three boolean conditions using logical OR (`||`) determines the answer in $\mathcal{O}(1)$ time per testcase.

2. **Alternative Sorting/Maximum Approach:**
   - The largest among the three integers must equal the sum of the remaining two. Hence, checking if $2 \times \max(a, b, c) = a + b + c$ is equivalent, though checking the three direct conditions avoids extra calculations.

3. **Constraints & Performance:**
   - The values $a, b, c$ fit comfortably within standard $32$-bit signed integers without overflow risks.
   - Fast I/O via `BufferedReader` and `StringBuilder` handles the large number of test cases ($t \le 9261$) efficiently.

4. **Complexity:**
   - **Time Complexity:** $\mathcal{O}(1)$ per testcase, yielding $\mathcal{O}(t)$ overall.
   - **Space Complexity:** $\mathcal{O}(1)$ auxiliary space.

---

### 💻 Java Solution

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;

/**
 * Problem: Sum (Codeforces 1742A)
 * Language: Java 8 / 11 / 17 / 21
 */
public class Sum {
    public static void main(String[] args) throws IOException {
        BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));
        String line = reader.readLine();
        if (line == null || line.trim().isEmpty()) {
            return;
        }

        int t = Integer.parseInt(line.trim());
        StringBuilder output = new StringBuilder();

        while (t-- > 0) {
            StringTokenizer st = new StringTokenizer(reader.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());
            int c = Integer.parseInt(st.nextToken());

            if (a + b == c || a + c == b || b + c == a) {
                output.append("YES\n");
            } else {
                output.append("NO\n");
            }
        }

        System.out.print(output);
    }
}
```
